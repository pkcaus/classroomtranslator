⚙ Settings, internet & privacy

For school use, your IT administrator should place Azure credentials behind a secure server/proxy. Entering an API key into a public HTML page exposes it to the device's users.

Microphone not reserved

Browser requirements: Web Speech Recognition needs browser support, microphone permissions and may need internet. Chrome on Mac or Safari on iPhone can be tried, but support varies by version/device. Microphone access may not work when opening a downloaded file directly; HTTPS hosting is more reliable. The browser controls whether permission persists, and Safari may still prompt each time speech recognition starts even if a microphone stream is open. For fewer prompts, allow microphone access for the website in the browser settings. Keeping the mic ready leaves the microphone active until released, unticked, or the page closes.

Privacy: Spoken audio can be processed by the browser's speech provider; recognised text goes to the selected translation provider. The public MyMemory option is for non-sensitive testing only. Seek school approval before translating student conversations. This app itself does not deliberately record or store audio. If “Keep microphone ready” is enabled, your device may show an active microphone indicator throughout that session. Recent text translations exist only in page memory and disappear on refresh. Use a qualified interpreter for sensitive or important conversations.

Made for short and supportive classroom exchanges. Please check translations before relying on them, especially when children are discussing feelings or needs.
